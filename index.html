一、品牌内容宪章

所有内容的“宪法”，任何内容不得违反。

必须遵守
1.1 品牌定位

德国柏曼 = 高端顶流 + 光品质

必须遵守
1.2 品牌人格与语气
  • 品牌人格：严谨、优雅、温暖、专业、创新
  • 语气：理性但不冰冷，专业但不卖弄，有温度但不煽情
  • 核心原则：“主体性叙事”——切换消费者视角，告诉用户“你为我做到了什么，别人没做到的”

营销绝对红线
  • ❌ 禁止低价内卷、夸大宣传、低俗博眼球
  • ❌ 禁止贬低同行，保持高端、严谨、温柔、绅士的沟通气质
  • ❌ 禁止只讲参数不讲用户价值，禁止品牌自嗨
  • ❌ 禁止品牌视角叙事，必须转化为“为你……”
  • ❌ 禁止没有科学出处的数据和声称

六、固定内容SOP

定义：一次性产出、上线后固定不变的内容。策划时需整合5阶段思考，最终产出1套完整方案。

SOP-01 · 固定内容
详情页策划案

适用品类：护眼灯 / 家居灯 / 家装灯  ｜  平台：天猫 / 京东

第一段 · 本质认知

用户打开详情页时，已经过了“随便看看”的阶段——他正在对比产品，准备做购买决策。详情页不是用来“吸引注意”的，是用来“说服下单”的。

用户行为本质用户心理你的内容要满足什么
划快速扫视，过滤无效信息“这跟我有关吗？”3秒内告诉他“有关”
看带着问题寻找答案“它能解决我的问题吗？”直接展示解决方案
比横向对比不同选项“凭什么选你不选别人？”给出不可辩驳的理由
怕担心买错/买贵/售后无保障“还有什么坑？”消除所有顾虑

详情页参照的决策阶段：④促决策为主，③种场景为辅。

第二段 · 4种内容逻辑

逻辑满足行为核心驱动力在详情页中的体现对应屏位
①建立认知划让用户知道“你是谁、什么档次”品牌形象、品牌故事第1屏
②解决疑问看让用户确认“能解决我的问题”痛点场景、解决方案第2-3屏
③提供证据比让用户相信“你说的是真的”认证、参数、检测报告第4-5屏
④消除顾虑怕让用户放心“不会有坑”服务保障、竞争胜选、行动引导第6-8屏

第三段 · 逻辑一：建立认知（第1屏）

公式（本逻辑专用）：品牌身份 + 核心定位 + 视觉冲击

品类第1屏内容
护眼灯画面：孩子在柏曼台灯下专注学习的温暖场景。文案：“国AA级护眼，德国标准认证” + “58年不跨界，只做灯”
家居灯画面：客厅/餐厅中柏曼吊灯营造的高级氛围感。文案：“德国设计，点亮品质家居” + “58年不跨界，只做灯”
家装灯画面：全屋灯光实拍效果图，见光不见灯的品质感。文案：“全屋好光，一套搞定” + “58年不跨界，只做灯”
拆解：画面用真实场景而非产品白底图；文案第一句给核心利益点（用户听得懂的标准）；文案第二句给品牌背书（58年不跨界建立专业信任）。

第四段 · 逻辑二：解决疑问（第2-3屏）

公式（本逻辑专用）：痛点场景 + 解决方案

品类第2屏（痛点）第3屏（解决方案）
护眼灯“孩子写作业揉眼、歪头、离书本越来越近……”“显色指数Ra≥95，还原真实色彩。普通台灯Ra80，颜色发白失真。”
家居灯“买了一盏好看的灯，装在家里却总感觉差点意思……”“包豪斯原创设计，全金属材质，关灯好看，开灯更好看。”
家装灯“装修到装灯环节才发现尺寸不对、光束角不会选……”“深度防眩+全光谱高显指，见光不见灯，舒适不刺眼。”
拆解：痛点用具体场景描写；解决方案第一句给结论；带对比让用户知道差距。

第五段 · 逻辑三：提供证据（第4-5屏）

公式（本逻辑专用）：权威认证 + 技术解读 + 真实场景

第4屏 · 科学背书区

  • 核心技术：紫光全光谱仿生自然光技术、减光衰芯片控温技术
  • 权威认证：UL钻石级光源验证 · 南德TÜV防蓝光认证 · IEC 62471 · 国家3C强制认证
  • 行业标准参与：参编 GB/T 24819-2023、T/SILA 012-2023 等多项国标/团标

第5屏 · 场景沉浸区

品类场景内容
护眼灯学习桌、阅读角、床头，孩子在不同场景下使用台灯的真实照片
家居灯客厅、餐厅、卧室，柏曼吊灯在不同家居风格中的融合效果
家装灯客厅无主灯设计、厨房操作照明、走廊洗墙效果
拆解：讲技术不讲参数（用户能感知的概念）；真实场景比样板间更可信。

第六段 · 逻辑四：消除顾虑（第6-8屏）

公式（本逻辑专用）：竞争胜选 + 服务保障 + 行动号召

第6屏 · 竞争胜选区

品类话术

家居灯“普通装饰灯追求短期颜值，柏曼为你做到三重耐看标准。”
家装灯“普通家装灯只讲亮度，柏曼为你做到深度防眩+科学配光。”

  • 12年性能质保——央企财险承保，行业独家
  • 品牌专属安装团队——不是第三方外包
  • 免费全屋灯光设计——专业设计师一对一
  • 流光计划免费测光——你亲自测，光品质你自己看

第8屏 · 行动号召区

立即购买 · 咨询客服 · 预约免费设计

第七段 · 逻辑之间的关系

用户心理关口对应逻辑你给的内容
“这是谁？”建立认知品牌+定位（第1屏）
“能解决我的问题吗？”解决疑问痛点+方案（第2-3屏）
“凭什么相信你？”提供证据认证+场景（第4-5屏）

总结

逻辑公式核心驱动力对应屏位
建立认知品牌身份+定位+视觉让用户知道“你是谁”第1屏
解决疑问痛点+方案让用户确认“能解决我的问题”第2-3屏
提供证据认证+技术+场景让用户相信“你说的是真的”第4-5屏
消除顾虑胜选+服务+行动让用户放心“不会有坑”第6-8屏
使用方式：
紧急需求 → 直接抄上述方案，替换品类和参数
日常需求 → 理解4种逻辑的递进关系，检查每屏是否完成任务
创意需求 → 跨屏逻辑组合（如在“解决疑问”中混入“建立认知”的元素）

第三段 · 逻辑一：解答案

公式（本逻辑专用）：用户提问 → 直接回答 → 提供依据 → 给出可执行方案

标题：护眼灯显色指数是什么？一篇讲清楚

显色指数（Ra）是衡量灯光还原物体真实颜色的能力。太阳光是Ra100，数值越高，颜色越真实。

国家规定读写台灯的显色指数不得低于Ra80。但“合格”和“好用”是两码事。Ra80的光线照在书本上，颜色发白发灰，眼睛更费力。柏曼护眼灯的显色指数做到Ra≥95，接近自然光。

选购时记住两个数：合格线Ra≥80（国标），好光线Ra≥95（柏曼标准）。回家看看你家台灯的参数标签，Ra低于80的，建议换掉。评论区留“Ra”，我把检测方法发给你。

第四段 · 逻辑二：解认知

公式（本逻辑专用）：指出常见误区 → 揭示原因 → 建立正确认知 → 给出新标准

标题：台灯越亮越好？90%的家长都搞反了

很多家长觉得护眼灯越亮越好。实际上这是一个误区。台灯的核心不是“亮”，而是“均匀”和“精准”。光线够亮但分布不均，孩子在灯下写作业时，书本中间亮、四周暗，瞳孔需要不断调节适应，反而更容易累。

国标对护眼灯的“照度均匀度”有明确的等级要求——AA级是目前最高等级。柏曼护眼灯做到国AA级照度，光线均匀覆盖整张书桌。不是更亮，是更均匀。

下次选灯，先看照度等级：A级是及格，AA级是好光。评论区留“AA”，我把照度检测方法发给你。

我终于明白，什么是“灯光是家的滤镜”。以前下班不想回家，现在下班就想快点开灯、窝在沙发里。一盏好灯，真的能改变一个家的情绪。

第六段 · 逻辑四：做判断

公式（本逻辑专用）：提出纠结 → 对比分析 → 给出明确结论 → 说明理由

标题：千元护眼灯和百元台灯，区别到底在哪？

给孩子选护眼灯，从几百到几千都有，区别到底在哪？我做了3组实测，结论非常明确。

光照范围：普通台灯（300元级）中心亮边缘暗，柏曼（千元级）整张书桌亮度均匀。频闪：普通台灯用手机摄像头能看到条纹滚动，柏曼完全无频闪。显色指数：普通台灯Ra80左右颜色发白发灰，柏曼Ra≥95颜色真实饱满。

结论：预算有限偶尔用灯→百元级够用；孩子每天用灯超2小时→千元级是刚需；追求光品质→柏曼。评论区留“孩子年龄+每天用灯时长”，我帮你判断。

第七段 · 逻辑五：共情感

公式（本逻辑专用）：分享真实经历 → 引发情感共鸣 → 建立信任 → 自然提及品牌

标题：用了半年柏曼，我来说点实话

好的方面：最明显的变化是孩子写作业不揉眼睛了。显色指数Ra95确实不一样，绘本上的颜色看起来舒服多了。

不够好的方面：价格确实不便宜。如果预算紧张，不用咬牙买。底座比较重，放在书桌上占地方。

总结：如果孩子每天用灯超过2小时，这笔投资值得。如果只是偶尔用，不用买这么贵的。理性消费，买适合自己的就好。

第八段 · 逻辑之间的关系

场景应该用哪个逻辑为什么
用户搜“护眼灯怎么选”解答案他带着具体问题来，你要给答案
用户搜“护眼灯是不是智商税”解认知他在质疑价值，你要建立认知
用户刷家居内容造向往他在“逛”不是在“搜”，你要激发向往
用户刷测评内容做判断他在“比较”不是在“搜”，你要帮决策
用户在评论区说“我家也这样”共情感他已经有共鸣了，用共情逻辑建立更深链接

总结

逻辑公式核心驱动力适合阶段
解答案提问→回答→依据→方案帮用户解决具体问题②做教育
解认知误区→揭示→新认知→标准打破旧认知，建立新标准②做教育
造向往理想→激发→可达成激发向往感、拥有欲③种场景
做判断纠结→对比→结论→理由帮用户做决定④促决策
共情感经历→共鸣→信任→品牌让用户觉得“你懂我”⑤扩口碑
跨逻辑切换才是真正的举一反三。 同一件事（如“柏曼护眼灯”），可以写成5种完全不同的内容：
  • 解答案：“护眼灯显色指数怎么看”
  • 解认知：“护眼灯越亮越好？错了”
  • 造向往：“晚上孩子写作业的画面，被这盏灯温柔了”
  • 做判断：“千元护眼灯和百元台灯，区别在哪”
  • 共情感：“用了半年柏曼，说点实话”

SOP-14 · 响应内容
售前售后话术

参照阶段：售前→④促决策 / 售后→⑤扩口碑

第一段 · 本质认知

用户状态用户在想什么你的沟通目标
①这是什么“我不懂这个概念”用通俗语言翻译
②真的有用吗“我不确定能不能解决”用证据和场景证明
③适合我吗“我不知道该选哪个”根据情况给建议

⑤万一出问题呢“担心售后无保障”明确说出保障内容

第二段 · 5种状态与对应公式

状态回答公式
①这是什么定义 → 类比 → 影响 → 品牌 → 追问
②真的有用吗共情 → 证据 → 场景 → 消虑 → 追问
③适合我吗确认 → 方案 → 理由 → 下一步
④怎么这么贵共情 → 重塑 → 换算 → 可信 → 反问
⑤万一出问题呢确认 → 机制 → 可信 → 升华

第三段 · 完整方案

状态①：这是什么（用户问“显色指数是什么？”）

“显色指数就是灯光还原物体真实颜色的能力（定义）。太阳光是Ra100（类比），普通台灯Ra80左右，光线照在书本上颜色发白发灰，眼睛更费力（影响）。柏曼护眼灯做到Ra≥95（品牌）。您家孩子现在多大？（追问）”

状态②：真的有用吗（用户问“真的不伤眼睛吗？”）

“很多家长都有同样的担心（共情）。我们的灯通过了国AA级和TÜV防蓝光认证（证据）。国AA是目前最高等级，光线均匀覆盖整张书桌，不会中间亮四周暗（场景）。30天无理由退换，您试用一个月再决定（消虑）。”

状态③：适合我吗（用户问“我家层高2.6m能装吗？”）

“可以装（确认）。吊链最短调至30cm，装好后离地2.2米，成人走动不碰头（方案）。建议搭配调光开关（理由）。下单后师傅免费上门测量安装（下一步）。”

状态④：怎么这么贵

“确实，第一次看到价格都觉得不便宜（共情）。普通台灯200-300元，3年光衰就要换，10年买3-4盏（重塑）。柏曼12年不用换，一天不到1块钱（换算）。央企财险承保（可信）。您看哪个更划算？（反问）”

状态⑤：万一出问题呢

“柏曼提供12年性能质保（确认）。12年内亮度不达标、光源损坏、开关失灵——免费维修或换新（机制）。央企财险承保（可信）。您买的是灯，我们保的是12年不用操心（升华）。”

第四段 · 拆解

状态最关键的一步为什么
①这是什么定义（第一步）必须先给定义，否则无法建立基本认知
②真的有用吗证据（第二步）要的不是“我信你”，是“你有证据”
③适合我吗确认（第一步）先确认“你听懂了我的情况”
④怎么这么贵重塑（第二步）不接受价格是因为把它看作“一次性支出”
⑤万一出问题呢机制（第二步）要的不是“有保障”，是“具体怎么解决”
